# 图片去水印工具

本地图片去水印工具，涂抹水印区域即可自动去除，全程在浏览器本地处理，**图片不会上传**到任何服务器。

## 文件说明

| 文件 | 用途 |
|------|------|
| `ImageWR.html` | 电脑版，双击即可用鼠标操作 |
| `mobile.html` | 手机版（PWA），可"添加到主屏幕"离线使用 |
| `manifest.webmanifest` / `sw.js` / `icon-*.png` | PWA 所需文件（离线缓存、图标） |
| `serve.js` | 本地测试服务器 |
| `gen-icons.js` | 重新生成图标（可选） |
| `auto-cut.js` | 智能抠除（自动识别物体边界）模块 |
| `vendor/u2netp.onnx` | 本地物体分割模型（约 4.4MB，智能抠除用） |

## 电脑版

直接双击 `ImageWR.html` 打开即可，无需任何环境。

## 手机版（PWA）

PWA 需要通过 `https://` 或 `localhost` 访问才能安装和离线使用，**直接双击 html 文件（file://）无法注册离线功能**。

### 方式一：局域网测试（推荐先试这个）

电脑装了 Node.js 后，**双击 `启动服务器.bat`** 即可（会自动启动并打印手机访问地址）。

也可以手动在命令行运行：

```bash
node serve.js
```

窗口会打印手机访问地址（形如 `http://192.168.x.x:8080/mobile.html`），手机连**同一个 WiFi**，用浏览器打开该地址即可使用。如果手机打不开，请允许 Windows 防火墙放行 Node.js。

> 注意：局域网 `http://` 下大多数浏览器可以正常使用去水印功能，但"安装到主屏幕/离线"因为不是 HTTPS 可能受限。要完整体验安装+离线，用方式二。

### 方式二：免费静态托管（可扫码安装、离线）

把这几个文件一起传到任意支持 HTTPS 的静态托管，即可扫码安装：

- **GitHub Pages**：新建仓库上传全部文件，开启 Pages，访问 `https://<用户名>.github.io/<仓库>/mobile.html`
- **Cloudflare Pages / Vercel / Netlify**：拖拽本文件夹即可部署

需要上传的文件：`mobile.html`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png`。

打开后：
- **安卓 Chrome**：顶部出现"安装"按钮，或浏览器菜单 → "添加到主屏幕"
- **iPhone Safari**：分享按钮 → "添加到主屏幕"

装好后就有一个独立图标，点开像 App 一样，断网也能用。

## 使用方法

1. 打开/选择带水印的图片
2. 用画笔（手机用手指）把水印涂成红色
3. 点"去除水印"
4. 效果不佳时可反复涂抹、反复去除（AI 修复默认已按最清晰、最精细处理）
5. 点"保存"导出结果；可在"保存格式"里选 PNG（无损）/ JPEG / WebP，JPEG 更适合上传发布
6. 点"对比原图"会出一条竖线：左侧是修改后、右侧是原图，拖动竖线来回对比（默认在最右，向左拖露出原图）

手机端：单指涂抹，双指缩放/移动。
电脑端：Ctrl+滚轮以鼠标为中心缩放。

## 智能抠除（自动识别物体边界）

要去除的物体边界明显、又怕画笔涂抹多涂/漏涂时，用"🎯 智能抠除"（相当于"智能涂抹/自动涂抹"）：

1. 在去水印模式下点"🎯 智能抠除"（手机为"🎯 智能"）
2. 用矩形框、圆形框或套索先圈出**一个小范围**（只圈住目标物体附近即可，不用很精确）
3. 软件会在这个范围内自动识别物体边界，把识别出的区域用蓝色编号标记出来
4. 点一下某个区域选中，它立刻变红——**和画笔涂抹出来的红完全一样**，可多选；再点一下可取消选中
5. 选中后还可以切回画笔/手指继续手动补涂，红色区域都会保留
6. 点"去除水印"，所有红色区域（点选的+涂抹的）一起消除，消除后照样可以撤销

物体识别在本机完成（u2netp 模型），图片同样不会上传。范围圈太大识别出的物体太多时，直接重新圈一个小范围即可。

## 豆包AI水印一键去除

选择照片的初始界面有一个「🧿 清除豆包AI水印」按钮（桌面在侧栏、手机在选择照片区域），专门去除豆包AI生成图片右下角的「豆包AI生成」白色字样：

1. 点该按钮，从相册选择一张图片
2. 软件自动在本机检测图片上是否有豆包AI水印
3. 识别到：水印区域自动标红，下方只显示「去除水印」一个按钮，点击即去除；去除后同样可以点「对比原图」拖动竖线查看效果
4. 未识别到：弹出短暂提示「未识别到豆包水印」后自动消失，并回到默认编辑区域（画笔/橡皮/智能抠除照常使用）

检测和去除全程在本机完成，图片不会上传。

## 手机版小提示

- 底部工具栏可点按收起/展开，收起后图片自动居中，方便查看
- 画笔/橡皮在图上涂抹时会有跟随的圆圈，方便精准定位
- 顶部「去除/添加/编辑」只保留图标以节省空间；图窗角落的 ✕ 可删除当前图片，回到选择照片页
